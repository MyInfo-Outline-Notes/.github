# MyInfo

> One named MyInfo tree. Finish the source. Leave a note the next outline can read.

## Session Card

| Slice | What you do in MyInfo | What remains |
|-------|------------------------|--------------|
| Outline | Open MyInfo and name today's research desk | A titled named tree |
| Source | Keep only live notes on the MyInfo board | A short document list |
| Handoff | Mark finished sources inside MyInfo | A note for the next visit |

## How MyInfo Sits

MyInfo does not replace the word processor, the browser, or the PDFs you already keep. It sits beside them as a named research desk for one job: which outline notes are live, which tree documents still match the named tree, and what the next person should read before the next source.

## Traffic Light

| Signal | On the MyInfo board | What you do |
|--------|----------------------|-------------|
| Green | Named tree, short live outline | Continue the same research desk |
| Amber | Two studies mixed in one document tree | Split the outline before a source |
| Red | No title, no note, files untitled | Stop and name the tree first |

## Open Order

1. Open the last MyInfo named tree, not a new empty research desk.
2. Read the outline notes and the last handoff.
3. Finish one visible tree document inside MyInfo.
4. Write what changed, then close with fewer untitled files than you found.

## Desk Fit

| Who | What MyInfo holds |
|-----|--------------------|
| Study desk | Outline notes, tree documents, and the source you cite |
| Shared PC | One MyInfo profile per person |
| Support | A repeatable MyInfo layout for the same tree |

## After a Week

A week in MyInfo is not a larger untitled file pile. It is the same title, a shorter live outline, and a note that still makes sense before the next source. Take finished documents off the live set so the next visit starts on the named tree that is still open.

## Sign-off

- [ ] The MyInfo workspace name is short enough to scan
- [ ] Only live notes sit on the tree
- [ ] A second person can read the outline handoff
- [ ] The last MyInfo tree still opens after a restart

## Field Note

MyInfo is easier to trust when the named tree stays smaller than the file pile it came from. Name the outline, keep the live documents, finish one visible source, and write what changed.
